# Workout Tracker

## Overview

I built this web app because I wanted a workout tracker that fits my needs. Before this, I only used my notes to record my workouts, but they often became unorganized. This app gives me a more organized way to track my workouts and exercises.

## Tech Stack

- **Backend:** ASP.NET Core 10 Minimal API
- **Frontend:** React 19, Vite
- **Database:** PostgreSQL 17
- **Tools:** Docker

## Features

- Create, view, update, and delete workouts.
- Email and password authentication using ASP.NET Core Identity.
- Add and remove exercises under each workout.
